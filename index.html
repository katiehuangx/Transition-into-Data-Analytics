Before you start

Hello, I'm Katie. This is my personal approach to self-studying data analytics, and the resources I'd point a friend to.

  • Self-study is hard. There is no syllabus, instructor or classmates, so you have to find your own answers and fix your own errors.
  • If time is tight, self-study may not be the best option. With consistency and determination it is still achievable.
  • Entry-level roles are competitive. A portfolio of real projects (last step) matters as much as any certificate.

I'm not an expert, just someone who is passionate about data analysis and wants to help others making this move. I'm not sponsored to recommend any course here. One disclosure: I previously worked on SQL content for DataLemur, which is listed in the tutorial and interview-prep sections. Resources I've personally tried and recommend are marked with a star.

  1. Start with a general course

    If you're curious about a data career but don't know where to begin, take a general data analytics course first. It gives you an overview of the field, an introduction to the tools you'll need, a study-at-your-own-pace format and a certificate for your CV.

    Both certificates below are on Coursera. At the time of writing, Coursera Plus was listed at around USD 59/month with a free trial, and Google's certificate is included in it. Prices change often, so check the course page. Financial aid may also be available. On average people finish in 2 to 6 months, and the faster you finish, the less you pay.

    I started with Google's because it was released more recently, in 2021. I found it very helpful as a visual learner. It covers spreadsheets, SQL (BigQuery), Tableau and R, and has since added AI-assisted modules. IBM's certificate takes a different route and includes a generative-AI-for-analysts course.

    Know what a certificate can and can't do

    Both courses are marketed as job-ready programmes. In my experience that isn't true. One course is not enough to get an entry-level job or pass a technical interview. At most it contributed 5 to 10% of my learning, so use it as a starting point and keep going with the steps below.

    Which SQL software to use

    You don't need to install anything to start. SQL Bolt, Select Star SQL, SQL Murder Mystery and Kaggle Learn all run in your browser. When you want your own local setup, these are the common free choices (they're called SQL flavours). The basics are the same across all of them, so pick the one your course uses and learn the differences later.

      Windows, Mac and Linux.

  4. 3

    Tableau or Power BI

    Tableau and Power BI are business intelligence and data visualization tools for building interactive dashboards and reports. Pick one first, because the skills transfer.

    Which one? Job-posting analyses disagree on whether Tableau or Power BI is ahead, and it varies by country and industry. Search job ads in the market you want to work in and learn the one that shows up more. Power BI Desktop is free (Windows) and Tableau Public is free, but everything you save there is public.

Using AI along the way

AI tools can now write SQL, Excel formulas and Python for you. That makes the fundamentals more important, not less, because you need to be able to tell when the output is wrong.

  • Learn SQL first. Then use AI as a tutor and a second pair of eyes, and always read and run the SQL or code it gives you.
  • Don't paste confidential company data or personal information into a public AI tool.
  • Google's Data Analytics certificate now includes modules on using AI for cleaning data, formulas and visualizations.

  • IBM: Generative AI for Data Analysts

    A structured option if you want a course.
