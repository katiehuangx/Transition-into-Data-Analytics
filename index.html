Before you start

Hi, I'm Katie. I'm sharing my experience on how I transitioned into data analytics and here are my resources.

  • Self-study is challenging. There's no syllabus, instructor or classmates, so you find your own answers and fix your own errors.
  • If time is tight, self-study may not be the best route. With consistency and determination it's still doable.
  • Entry-level roles are competitive. A portfolio of real projects (the last step) matters more than any certificate.

No course here sponsors me.

    Start with a general course

    If you're curious about a data career but don't know where to begin, take a general data analytics course first, like Google's. It gives you an overview of the field, an introduction to the skills and tools you'll learn, a study-at-your-own-pace format and a certificate for your resume.

    Google's covers spreadsheets, SQL (BigQuery), Tableau and R, and has since added AI-assisted modules. On average people finish it in 2 to 6 months, and the faster you finish, the less you pay.

    You don't need both options below. Pick one to start, then move on to the steps after it.

    This course is marketed as a job-ready programme. In my experience that isn't true. One course is not enough to get an entry-level job or pass a technical interview. At most it contributed 5 to 10% of my learning, so use it as a starting point and keep going with the steps below.

      Excel and Google Sheets

      Excel is still one of the most common skills in data analyst job ads, and you'll likely use it every week at work. Don't skip it. Alex the Analyst's bootcamp (first step) also has an Excel section.

      Skills to learn

      • Lookup: XLOOKUP, INDEX/MATCH.
      • Conditional formulas: SUMIFS, COUNTIFS, AVERAGEIFS, IF, IFS.
      • Dynamic arrays: FILTER, SORT, UNIQUE, SEQUENCE.
      • Text and date manipulation.
      • PivotTables and PivotCharts.
      • Power Query for cleaning and transforming data.
      • Data validation and conditional formatting.
      • Google Sheets QUERY, ARRAYFORMULA, FILTER and IMPORTRANGE.
      • Basic automation using Office Scripts or Google Apps Script.

      Important: Power Query is particularly valuable for analysts who repeatedly receive CSV files or Excel exports that need cleaning and combining.

      SQL

      SQL is the easiest and most essential skill for any data analyst role. It's how you extract, manipulate and analyze data, and once you know it, other tools get easier (Tableau's calculated fields use SQL-style logic).

      Skills to learn

      • Querying: SELECT, WHERE, ORDER BY, LIMIT.
      • Aggregation: COUNT, SUM, AVG, GROUP BY, HAVING.
      • Joins: INNER JOIN and LEFT JOIN, and when to use each.
      • Conditional logic: CASE WHEN.
      • Subqueries and CTEs.
      • Window functions: ROW_NUMBER, RANK, LAG, LEAD, running totals.
      • Dates and strings: date functions, string functions.
      • Cleaning data: NULLs, duplicates, DISTINCT, COALESCE.

      Important: Joins and window functions come up most often in interviews.

      Python

      Python is not always required for data analysts. In some companies it's only good-to-have, in others it's a must-have. Learn it if you're aiming at tech companies or at data scientist or data engineer roles.

      Either way, get comfortable with SQL, a spreadsheet tool and one BI tool first.

      For setup, Alex's bootcamp includes a video on installing Jupyter Notebook and Anaconda. Kaggle's free notebooks also run in your browser with nothing to install.

      Skills to learn

      • Basics: variables, data types, loops, functions, lists and dictionaries.
      • pandas: loading CSV and Excel files, filtering, sorting.
      • Cleaning data: missing values, duplicates, data types, dates and text.
      • Combining and summarising: groupby, merge, pivot tables.
      • NumPy basics.
      • Charts with matplotlib or seaborn.
      • Working in Jupyter notebooks.
      • Loading SQL query results into pandas.

      Important: pandas is the part analysts use most, so spend most of your time there.

    Using AI along the way

    AI tools can now write SQL, Excel formulas and Python for you. That makes the fundamentals more important, not less, because you need to be able to tell when the output is wrong.

    • Learn SQL first. Then use AI as a tutor and a second pair of eyes, and always read and run the SQL or code it gives you.
    • Don't paste confidential company data or personal information into a public AI tool.
    • Google's Data Analytics certificate now includes modules on using AI for cleaning data, formulas and visualizations.
