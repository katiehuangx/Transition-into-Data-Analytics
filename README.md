## How and Where to Start?

If you're reading this, you're probably interested in starting a career in data analytics, but don't know where to begin or whether it's the right path for you. I totally get it - I was once in your shoes! 🧐

**👩🏻‍💻 Course**
To start, I recommend taking a **general data analytics course** like the [Google Data Analytics](https://www.coursera.org/professional-certificates/google-data-analytics) which covers spreadsheets, SQL (BigQuery), Tableau and R and has since added AI-assisted modules.

This course provides:
- An **overview of data analytics**
- An **introduction to the skills and tools** you'll learn
- Flexible, study-at-your-own-pace courses
- A certificate you can put on your resume

On average, people complete these in 2 to 6 months and the faster you complete it, the less you pay. 😇

**‼️IMPORTANT‼️**
- This course is marketed as job-ready programmes. In my experience, that's not true. 🥲
- What you learn from one course is **NOT ENOUGH to get an entry-level job** or pass a technical interview.
- At most, the course contributed 5-10% to my learning.

**🏕️ Bootcamp**

I highly recommend Alex the Analyst's free [data analyst bootcamp](https://www.youtube.com/playlist?list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF) on YouTube. It covers SQL, Excel, Tableau, Power BI, Python and portfolio projects. It's an excellent resource if you're new to data analytics or want to improve your skills in any of these tools.

You don't need both options above. Pick one to start, then move on to the steps after it.

Thus, I'm sharing the following resources to help you continue your studies after completing the course.

## My Advice on Skills to Learn

In my opinion, you should focus on these skills in the following order:
1. Excel / Google Sheets (you'll likely use it every week at work)
2. Statistics (basics)
3. SQL
4. Tableau / Power BI (pick one, the skills transfer)
5. Python

I found SQL to be the **easiest and most essential skill** for any data analyst role. It's a crucial language for extracting, manipulating, and analyzing data. Once you understand SQL, you'll have an easier time learning other tools like Tableau, which relies on SQL-style logic for calculated fields.

Python is not always required for data analysts. In some companies, it's only good-to-have, while in others it's a must-have. Learn it if you're aiming at tech companies or at data scientist or data engineer roles.

# 📈 Where to Learn Excel & Google Sheets

Excel is still one of the most common skills in data analyst job ads, so don't skip it.

### 🎯 Skills to Learn
- Lookup: XLOOKUP, INDEX/MATCH.
- Conditional formulas: SUMIFS, COUNTIFS, AVERAGEIFS, IF, IFS.
- Dynamic arrays: FILTER, SORT, UNIQUE, SEQUENCE.
- Text and date manipulation.
- PivotTables and PivotCharts.
- Power Query for cleaning and transforming data.
- Data validation and conditional formatting.
- Google Sheets QUERY, ARRAYFORMULA, FILTER and IMPORTRANGE.
- Basic automation using Office Scripts or Google Apps Script.

**Important:** Power Query is particularly valuable for analysts who repeatedly receive CSV files or Excel exports that need cleaning and combining.

# 📕 Where to Learn SQL

🌟 is my tried-and-tested favourite.

### 🎯 Skills to Learn
- Querying: SELECT, WHERE, ORDER BY, LIMIT.
- Aggregation: COUNT, SUM, AVG, GROUP BY, HAVING.
- Joins: INNER JOIN and LEFT JOIN, and when to use each.
- Conditional logic: CASE WHEN.
- Subqueries and CTEs.
- Window functions: ROW_NUMBER, RANK, LAG, LEAD, running totals.
- Dates and strings: date functions, string functions.
- Cleaning data: NULLs, duplicates, DISTINCT, COALESCE.

**Important:** Joins and window functions come up most often in interviews.

### 💻 Which SQL Software to Use?

When you want your own local setup, these are the common free choices. In tech-speak, we call them SQL flavours.
- PostgreSQL (Windows, Mac, Linux, free) - https://www.postgresql.org/download/
- MySQL Workbench (Windows and Mac, free) - https://www.mysql.com/products/workbench/
- Microsoft SQL Server (Alex Freberg's course uses it. The free Express edition is enough for learning) - https://www.microsoft.com/en-us/sql-server/sql-server-downloads

The basics are the same across all of them. Pick the one your course uses and learn the differences later.

# 🐍 Where to Learn Python

For setup, Alex's [data analyst bootcamp](https://www.youtube.com/playlist?list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF) includes a video on installing Jupyter Notebook/Anaconda. Kaggle's free notebooks also run in your browser with nothing to install.

Python can wait. Get comfortable with SQL, a spreadsheet tool and one BI tool first, unless the roles you're aiming for ask for it.

### 🎯 Skills to Learn
- Basics: variables, data types, loops, functions, lists and dictionaries.
- pandas: loading CSV and Excel files, filtering, sorting.
- Cleaning data: missing values, duplicates, data types, dates and text.
- Combining and summarising: groupby, merge, pivot tables.
- NumPy basics.
- Charts with matplotlib or seaborn.
- Working in Jupyter notebooks.
- Loading SQL query results into pandas.

**Important:** pandas is the part analysts use most, so spend most of your time there.

# 🤖 Using AI as a Data Analyst

AI tools can now write SQL, Excel formulas and Python for you. That makes learning the fundamentals more important, not less, because you need to be able to tell when the output is wrong.

- Learn SQL first. Then, use AI as a tutor and a second pair of eyes, and always read and run the SQL or code it gives you.
- Don't paste confidential company data or personal information into a public AI tool.
- Google's Data Analytics certificate now includes modules on using AI for cleaning data, formulas and visualizations.

# How to Create a Portfolio on GitHub

Looking to showcase your coding projects and skills to potential employers or clients? Creating a portfolio on GitHub is a great way to do so.

Check out this guide on how to create a portfolio on GitHub: https://github.com/katiehuangx/How-to-Create-a-GitHub-Portfolio/blob/main/README.md

You can also refer to my [portfolio](https://github.com/katiehuangx/Portfolio-Guide/blob/main/README.md) for inspiration on structure and content.

Once you have a project, practise explaining it. Here are datasets to build on.

### 📊 Practice Datasets

**Malaysia**
1. data.gov.my [Free] - Malaysia's open data portal, with datasets from federal and state agencies. Download them or connect through an API - https://data.gov.my/data-catalogue
2. OpenDOSM [Free] - The Department of Statistics Malaysia's open data on population, prices, labour and GDP. CSV and Parquet downloads, free to reuse under a Creative Commons licence - https://open.dosm.gov.my/data-catalogue
3. Public transport ridership [Free] - Daily ridership data for public transport services across Malaysia. Good raw material for a dashboard - https://data.gov.my/data-catalogue/ridership_headline
4. Bank Negara Malaysia rates and statistics [Free] - Interest rates and other central bank statistics. Download as CSV or use the API. Credit "Source: Bank Negara Malaysia" if you publish your work - https://apikijangportal.bnm.gov.my/
5. MoH COVID-19 data [Free] - The Ministry of Health's official COVID-19 data on GitHub, including cases, hospital admissions and vaccinations as CSV files. It's historical, so best for practising time series and data cleaning - https://github.com/MoH-Malaysia/covid19-public

**Global**
1. World Bank Open Data [Free] - Economic, health and other indicators for Malaysia and every other country. Download as Excel or CSV from any data page - https://data.worldbank.org/country/malaysia
2. Kaggle Datasets [Free] - A huge library of public datasets. You can browse without an account, but you need a free account to download - https://www.kaggle.com/datasets
3. Google Dataset Search [Free] - A search engine for datasets, wherever they're hosted. Use it when you have a topic but no data - https://datasetsearch.research.google.com/
4. Maven Analytics Data Playground [Free] - Free sample datasets picked by Maven instructors, from flight delays to movie ratings. Good raw material for a portfolio project - https://mavenanalytics.io/data-playground
