# How I Transition into Data Analytics (Self-Study Route)

_(updated on 18 Nov 2026)_

Hello, I'm Katie and I'm sharing my personal experience and approach to self-studying for data analytics.

**📕 My Study Approach**
- As a **visual learner**, I prefer watching video tutorials over reading textbooks to better understand how the code works on my screen.

**🧐 What You Should Know**
- Self-studying can be **challenging** because you are on your own without any syllabus, instructors or classmates to guide you.
- It requires resourcefulness in finding solutions and troubleshooting errors.
- If time is a constraint, self-study may not be the best option. However, with consistency, hard work and determination, it is achievable.
- Entry-level roles are competitive. A portfolio of real projects (see the last section) matters as much as any certificate.

**Disclaimer**: I'm not an expert, just someone who is passionate about data analysis and wants to help others who are transitioning into this field.

**Another important note:** I'm not sponsored to recommend any of the courses mentioned below. One disclosure: I previously worked on SQL content for DataLemur which is listed in the interview-prep section.

**Prices and availability change.** Check each link before you pay for anything.

## How and Where to Start?

If you're reading this, you're probably interested in starting a career in data analytics, but don't know where to begin or whether it's the right path for you. I totally get it - I was once in your shoes! 🧐

To start, I recommend taking a **general data analytics course**, like the [Google Data Analytics](https://www.coursera.org/professional-certificates/google-data-analytics) or the [IBM Data Analyst](https://www.coursera.org/professional-certificates/ibm-data-analyst) certificate. I started with Google's course as it was released more recently. I'm not sponsored for either.

Both courses provide:
- An **overview of data analytics**
- An **introduction to the skills/tools** you need to learn
- Flexible, study-at-your-own-pace courses
- A certificate you can put on your CV

Both are on Coursera. At the time of writing, Coursera Plus was listed at around USD 59/month with a free trial, and Google's certificate is included in it. Prices change often, so check the course page. Financial aid may also be available. On average, people complete these in 2 to 6 months, and the faster you complete it, the less you pay. 😇

**💡 My Experience**

I found Google's course very helpful, especially since I'm a visual learner. It covers spreadsheets, SQL (BigQuery), Tableau and R, and has since added AI-assisted modules. You'll still need additional courses for in-depth knowledge. IBM's certificate takes a different route and includes a generative-AI-for-analysts course.

**‼️IMPORTANT‼️**
- Both courses are marketed as job-ready programmes. In my experience, that's not true. 🥲
- What you learn from one course is **NOT ENOUGH to get an entry-level job** or pass a technical interview.
- At most, the course contributed 5% or less of my learning.

Thus, I'm sharing the following resources to help you continue your studies after completing the course.

## My Advice on Technical Skills to Learn

In my opinion, you should focus on these skills in the following order:
1. SQL
2. Excel / Google Sheets (you'll likely use it every week at work)
3. Tableau **or** Power BI (pick one, the skills transfer)
4. Python & Statistics

I found SQL to be the **easiest and most essential skill** for any data analyst role. It's a crucial language for extracting, manipulating, and analyzing data. Once you understand SQL, you'll have an easier time learning other tools like Tableau, which relies on SQL-style logic for calculated fields.

Python is not always required for data analysts. In some companies it's only good-to-have, while in others it's a must-have. Learn it if you're aiming at tech companies or at data scientist or data engineer roles.

**Which BI tool should you pick?** Job-posting analyses disagree on whether Tableau or Power BI is ahead and it varies by country and industry. Search job ads in the market you want to work in and learn the one that shows up more. Power BI Desktop is free (Windows) and Tableau Public is free, but everything you save there is public.

### 💻 Which SQL Software to Use?

You don't need to install anything to start. SQL Bolt, Select Star SQL, SQL Murder Mystery and Kaggle Learn all run in your browser.

When you want your own local setup, these are the common free choices. In tech-speak, we call them SQL flavours.
- PostgreSQL (Windows, Mac, Linux) - https://www.postgresql.org/download/
- MySQL (Windows and Mac) - https://www.mysql.com/products/workbench/
- Microsoft SQL Server (Alex Freberg's course uses it)

The basics are the same across all of them. Pick the one your course uses, and learn the differences later.

# 🤖 Using AI as a Data Analyst

AI tools can now write SQL, Excel formulas and Python for you. That makes learning the fundamentals more important, not less, because you need to be able to tell when the output is wrong.

- Learn SQL first. Then, use AI as a tutor and a second pair of eyes, and always read and run the SQL or code it gives you.
- Don't paste confidential company data or personal information into a public AI tool.
- Google's Data Analytics certificate now includes modules on using AI for cleaning data, formulas and visualizations.
- IBM's [Generative AI for Data Analysts](https://www.coursera.org/specializations/generative-ai-for-data-analysts) specialization is a structured option if you want a course.
